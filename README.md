## 🚀 How to use:

🔄 To run it, simply execute:
```bash
go run main.go
```

⚙️ You can change the API by modifying the `url` variable. 
⚠️ However, it is highly recommended to use an API from **Open-Meteo**, as the code is pre-configured to parse its specific JSON structure.
